## 🚀 Featured Individual Projects

### 💳 Credit Risk Scoring & Financial Risk Analysis

**Python · XGBoost · Scikit-learn · Streamlit · Plotly**

Built an end-to-end **credit default prediction and decision-support prototype** using the UCI Default of Credit Card Clients dataset (**30,000 records**).

- Developed and evaluated classification models, selecting **XGBoost** for the final application.
- Used separate training, calibration, and test datasets to select and assess a **0.31 classification threshold**.
- Built an interactive Streamlit application for individual risk predictions, customer segmentation, and portfolio-level analysis.
- Included a demonstration of **expected credit loss** using probability of default and adjustable assumptions.
- **Test results:** ROC-AUC **0.762** · Accuracy **79.73%** · F1-score **0.507**.

*Academic decision-support prototype; not a production banking decision system.*

### 🏦 [Bank Customer Churn Prediction](https://github.com/chamudi01/bank-churn-prediction)

**Python · Pandas · Scikit-learn · Matplotlib · Seaborn**

Developed a machine learning workflow to predict which banking customers may leave and investigate factors associated with churn.

- Prepared and analyzed **9,985 customer records** using cleaning, feature encoding, scaling, and exploratory analysis.
- Compared Logistic Regression, Ridge Regression, Lasso Regression, and Decision Tree approaches.
- Identified customer age, activity status, and geography as important factors in the analysis.
- **Selected model:** Decision Tree · **ROC-AUC 0.83** · **Accuracy 85.38%**.

### 📰 Financial News Sentiment Analysis

**Python · NLP · TF-IDF · Linear SVM · NLTK · Gradio**

Created a financial text classification application that categorizes news into **positive, negative, or neutral** sentiment.

- Processed **3,447 financial news sentences** from the Financial PhraseBank dataset.
- Applied tokenization, stopword removal, lemmatization, and TF-IDF feature extraction.
- Compared Naive Bayes, Logistic Regression, and Linear SVM.
- Built a **Gradio interface** for interactive sentiment predictions.
- **Best model:** Linear SVM · **Accuracy 82.90%** · **F1-score 82.23%**.

### 📈 Apple Stock Price Forecasting with ARIMA & SARIMA

**Python · Statsmodels · Pandas · Matplotlib · Jupyter Notebook**

Explored classical time series methods for forecasting historical **Apple (AAPL) stock closing prices**.

- Prepared and visualized historical stock data and examined trends.
- Assessed stationarity using the **Augmented Dickey–Fuller (ADF) test**.
- Used **ACF/PACF** analysis to support model identification.
- Applied **ARIMA and SARIMA** models and evaluated forecasts using RMSE and AIC.

*An educational forecasting study, not an investment recommendation.*
